🚀 Instalação & Configuração

Guia passo a passo para integrar o Nano-Spring ao seu projeto Android, expor serviços REST locais e manter o servidor rodando em segundo plano de forma confiável.

📱 Requisitos de Hardware & Sistema

O Nano-Spring é ultra-leve e consome entre 15 MB e 40 MB de memória RAM, operando com total fluidez mesmo em smartphones de entrada e terminais POS com 1 GB de RAM:

Componente Mínimo Suportado Recomendado
Versão do Android Android 7.1.1 (API 25 - Nougat) Android 10+ (API 29+)
Compatibilidade Java Java 11 Java 17
Memória RAM Consumida ~15 MB a 40 MB Qualquer aparelho com 1GB+ total
Arquitetura da CPU ARMv7 (32-bit), ARM64 ou x86_64 Qualquer processador Quad-core 1.3GHz+

📦 Instalação Passo a Passo

Escolha a forma de distribuição ideal para o seu ambiente de desenvolvimento:

1

Configure suas credenciais do GitHub

O GitHub Packages requer autenticação via token pessoal (PAT) com escopo read:packages para baixar bibliotecas.

Adicione no arquivo ~/.gradle/gradle.properties do seu computador (ou na raiz do projeto):

~/.gradle/gradle.properties 
gpr.user=SEU_USUARIO_GITHUB
gpr.key=SEU_PERSONAL_ACCESS_TOKEN
2

Declare o repositório Maven

Configure a resolução de dependências no settings.gradle da raiz do seu projeto Android.

settings.gradle 
dependencyResolutionManagement {
    repositoriesMode.set(RepositoriesMode.FAIL_ON_PROJECT_REPOS)
    repositories {
        google()
        mavenCentral()
        maven {
            url = uri("https://maven.pkg.github.com/matheuscruzsouza/nano-spring")
            credentials {
                username = providers.gradleProperty("gpr.user").orNull ?: System.getenv("GITHUB_ACTOR") ?: ""
                password = providers.gradleProperty("gpr.key").orNull ?: System.getenv("GITHUB_TOKEN") ?: ""
            }
        }
    }
}
3

Adicione a dependência da biblioteca

No build.gradle do seu módulo da aplicação (geralmente app/build.gradle):

app/build.gradle 
dependencies {
    implementation 'com.github.matheuscruzsouza:nano-spring:1.10.0'
}
4

Declare as permissões no AndroidManifest.xml

Para abrir portas de socket HTTP, monitorar rede e anunciar via mDNS Zeroconf:

app/src/main/AndroidManifest.xml 
<manifest xmlns:android="http://schemas.android.com/apk/res/android">

    <!-- Permissões de rede essenciais -->
    <uses-permission android:name="android.permission.INTERNET" />
    <uses-permission android:name="android.permission.ACCESS_NETWORK_STATE" />
    <uses-permission android:name="android.permission.ACCESS_WIFI_STATE" />

    <!-- Obrigatório para descoberta Zeroconf / mDNS (.local) -->
    <uses-permission android:name="android.permission.CHANGE_WIFI_MULTICAST_STATE" />

    <!-- Recomendado para operação contínua 24/7 sem suspensão -->
    <uses-permission android:name="android.permission.WAKE_LOCK" />
    <uses-permission android:name="android.permission.FOREGROUND_SERVICE" />

    <application
        android:usesCleartextTraffic="true"
        ... >
    </application>
</manifest>
5

Crie seu primeiro Controller REST

Exatamente como no Spring Boot, use anotações limpas para expor rotas HTTP:

OlaController.java 
package com.seupacote.controllers;

import com.github.matheuscruzsouza.nanospring.annotation.GetMethod;
import com.github.matheuscruzsouza.nanospring.annotation.RestController;
import com.github.matheuscruzsouza.nanospring.http.ResponseEntity;

import java.util.Map;

@RestController("/api")
public class OlaController {

    @GetMethod("/ola")
    public ResponseEntity<Map<String, Object>> dizerOla() {
        return ResponseEntity.ok(Map.of(
            "status", "online",
            "mensagem", "Servidor Nano-Spring rodando nativamente no Android!"
        ));
    }
}
6

Inicialize o Servidor em Segundo Plano

Utilize a classe base NanoSpringService para garantir que o Android mantenha o servidor ativo com notificação persistente e travas de Wi-Fi:

ServidorService.java 
package com.seupacote.services;

import com.github.matheuscruzsouza.nanospring.service.NanoSpringService;

public class ServidorService extends NanoSpringService {

    @Override
    public int getServerPort() {
        return 8080; // Ou porta definida no application.properties
    }

    @Override
    public String getBasePackage() {
        return "com.seupacote"; // Pacote raiz que será escaneado
    }
}
💡
Pronto! Ao iniciar o serviço, sua API estará disponível localmente em http://<ip-do-dispositivo>:8080/api/ola ou pelo hostname Zeroconf http://servidor.local:8080/api/ola.

Se você clonou o repositório do nano-spring e incluiu o projeto como módulo local no settings.gradle:

settings.gradle 
include ':app'
include ':nano-spring'
project(':nano-spring').projectDir = new File(rootDir, '../nano-spring')

Em seguida, declare no app/build.gradle:

app/build.gradle 
dependencies {
    implementation project(':nano-spring')
}
