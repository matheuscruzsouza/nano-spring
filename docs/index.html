O poder do Spring Boot dentro do seu Android

Transforme qualquer celular, tablet, TV-Box ou POS Android em um servidor web de alta performance. APIs REST, injeção de dependências, banco SQLite versionado e mDNS consumindo entre 15 e 40 MB de RAM.

Começar Agora 🚀 Comparar com Spring Boot ⚖️ Repositório no GitHub ↗

⚡ Início Rápido em 3 Passos

Construir um servidor web local em Java para Android nunca foi tão simples:

1. Adicione a dependência no Gradle

app/build.gradle 
dependencies {
    implementation 'com.github.matheuscruzsouza:nano-spring:1.10.0'
}

2. Inicie o servidor em um Service Android

AppServerService.java 
public class AppServerService extends com.github.matheuscruzsouza.nanospring.service.NanoSpringService {
    @Override
    public int getServerPort() {
        return 8080;
    }

    @Override
    public String getBasePackage() {
        return "com.exemplo.meuapp";
    }
}

3. Crie seu primeiro Controller REST

HelloController.java 
@RestController("/api")
public class HelloController {

    @GetMethod("/ola")
    public Map<String, String> dizerOla() {
        return Map.of(
            "status", "online",
            "mensagem", "Servidor rodando nativamente no Android!"
        );
    }
}
💡
Acesse direto do navegador no mesmo Wi-Fi: http://<ip-do-celular>:8080/api/ola ou via mDNS http://androidserver.local:8080/api/ola.
