O poder do Spring Boot dentro do seu Android

Transforme qualquer celular, tablet ou POS Android em um servidor web de alta performance. APIs REST, injeção de dependências, banco SQLite versionado e mDNS consumindo entre 15 e 40 MB de RAM.

Começar Agora 🚀 Comparar com Spring Boot ⚖️ GitHub ↗

⚡ Início Rápido em 3 Passos

Construir um servidor web local em Java para Android nunca foi tão simples:

1. Adicione a dependência no Gradle

build.gradle (app) 
dependencies {
    implementation 'com.github.matheuscruzsouza:nano-spring:1.6.0'
}

2. Inicie o servidor em um Service Android

AppServerService.java 
public class AppServerService extends android.app.Service {
    private Server server;

    @Override
    public int onStartCommand(Intent intent, int flags, int startId) {
        // Inicializa o servidor na porta 8080 varrendo as anotações do seu pacote
        server = new Server(this, 8080, "com.exemplo.meuapp");
        return START_STICKY;
    }

    @Override
    public void onDestroy() {
        if (server != null) server.stop();
        super.onDestroy();
    }
}

3. Crie seu primeiro Controller REST

HelloController.java 
@RestController("/api")
public class HelloController {

    @GetMethod("/ola")
    public Map<String, String> dizerOla() {
        return Map.of(
            "status", "online",
            "mensagem", "Servidor rodando nativamente no Android!"
        );
    }
}
💡
Acesse direto do navegador no mesmo Wi-Fi: http://<ip-do-celular>:8080/api/ola ou via mDNS http://androidserver.local:8080/api/ola.
