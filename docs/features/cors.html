🛡️ Módulo Nativo de CORS

O Nano-Spring possui suporte integrado e declarativo a Cross-Origin Resource Sharing (CORS), eliminando dores de cabeça ao consumir as rotas do celular a partir de aplicações frontend modernas (React, Vue, Angular, Svelte ou páginas web externas).

⚡ Recursos Principais

  • Ativado por padrão: Pronto para uso imediato com política permissiva (nano.cors.enabled=true).
  • Pre-flight Automático: Requisições HTTP com método OPTIONS são interceptadas imediatamente pelo pipeline, retornando 200 OK com corpo vazio e cabeçalhos CORS completos, sem acionar controladores ou gastar processamento.
  • Injeção Global: Cabeçalhos são injetados em requisições bem-sucedidas, respostas de arquivos estáticos, streams SSE e respostas de erro tratadas por @ControllerAdvice.
  • Zero Overhead: Caso desabilitado (nano.cors.enabled=false), o overhead é de apenas uma checagem booleana.

⚙️ Configuração via application.properties

assets/application.properties 
# Habilita ou desabilita o filtro global (padrão: true)
nano.cors.enabled=true

# Origens permitidas separadas por vírgula (padrão: *)
nano.cors.allowed-origins=http://localhost:3000,https://meuapp.com

# Métodos HTTP aceitos (padrão: GET,POST,PUT,DELETE,OPTIONS)
nano.cors.allowed-methods=GET,POST,PUT,DELETE,OPTIONS

# Cabeçalhos permitidos (padrão: Content-Type,Authorization,X-Requested-With,Accept)
nano.cors.allowed-headers=Content-Type,Authorization,X-Requested-With,Accept,X-Custom-Token

# Cache em segundos para pre-flight (padrão: 86400 = 24 horas)
nano.cors.max-age=86400

💻 Ajuste Programático em Tempo de Execução

CorsSetup.java 
import com.github.matheuscruzsouza.nanospring.cors.CorsConfiguration;

// Acessa a configuração de CORS do servidor:
CorsConfiguration cors = server.getCorsConfiguration();

// Configura regras customizadas dinamicamente:
cors.setAllowedOrigins("https://dashboard.meuapp.com");
cors.setAllowedHeaders("Content-Type,Authorization,X-Tenant-ID");
cors.setMaxAge(3600); // 1 hora de cache pre-flight
💡
A instância de CorsConfiguration também é registrada como Singleton no container de injeção e pode ser injetada via @Autowired em qualquer serviço.
