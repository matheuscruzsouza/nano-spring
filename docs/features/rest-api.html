🌐 Construindo APIs RESTful

O Nano-Spring fornece anotações declarativas para construir endpoints HTTP de forma rápida e elegante, seguindo as convenções consagradas do Spring Boot.

📌 Resumo das Anotações

Anotação Alvo Descrição
@RestController(prefix) Classe Registra a classe como controller REST e define a rota base
@GetMethod(path) Método Mapeia requisições GET
@PostMethod(path) Método Mapeia requisições POST
@PutMethod(path) Método Mapeia requisições PUT
@DeleteMethod(path) Método Mapeia requisições DELETE
@PathVariable(name) Parâmetro Captura variáveis declaradas na rota com :nome
@RequestParam(name) Parâmetro Extrai parâmetros de Query String (ex: ?pagina=1)
@RequestHeader(name) Parâmetro Injeta cabeçalhos HTTP com suporte a default value, required e conversão de tipo
@RequestBody Parâmetro Desserializa o corpo JSON da requisição em um POJO Java via Gson

💡 Exemplo Prático: CRUD REST

Veja como criar um controller completo com listagem, busca por ID, criação, atualização e exclusão:

UserController.java 
package com.exemplo.meuapp.controllers;

import com.github.matheuscruzsouza.nanospring.annotation.*;
import com.github.matheuscruzsouza.nanospring.http.HttpStatus;
import com.github.matheuscruzsouza.nanospring.http.ResponseEntity;
import com.exemplo.meuapp.model.User;
import com.exemplo.meuapp.service.UserService;

import java.util.List;

@RestController("/api/users")
public class UserController {

    @Autowired
    private UserService userService;

    // GET /api/users ou /api/users?status=ativo
    @GetMethod("")
    public List<User> listUsers(@RequestParam(value = "status", required = false) String status) {
        if (status != null) {
            return userService.findByStatus(status);
        }
        return userService.findAll();
    }

    // GET /api/users/42
    @GetMethod("/:id")
    public ResponseEntity<User> getUserById(@PathVariable("id") Long id) {
        User user = userService.findById(id);
        if (user == null) {
            return ResponseEntity.status(HttpStatus.NOT_FOUND).build();
        }
        return ResponseEntity.ok(user);
    }

    // POST /api/users
    @PostMethod("")
    @ResponseStatus(HttpStatus.CREATED)
    public User createUser(@RequestBody User newUser) {
        return userService.save(newUser);
    }

    // PUT /api/users/42
    @PutMethod("/:id")
    public ResponseEntity<User> updateUser(@PathVariable("id") Long id, @RequestBody User user) {
        User updated = userService.update(id, user);
        return ResponseEntity.ok(updated);
    }

    // DELETE /api/users/42
    @DeleteMethod("/:id")
    public ResponseEntity<Void> deleteUser(@PathVariable("id") Long id) {
        userService.delete(id);
        return ResponseEntity.status(HttpStatus.NO_CONTENT).build();
    }
}

🛡️ Injetando Cabeçalhos com @RequestHeader

Injete valores de cabeçalhos HTTP com suporte a case-insensitivity, obrigatoriedade e valores padrão:

HeaderController.java 
@RestController("/api/auth")
public class AuthController {

    // 1. Cabeçalho obrigatório (retorna 400 Bad Request se não for enviado)
    @GetMethod("/profile")
    public ResponseEntity<User> getProfile(@RequestHeader("Authorization") String token) {
        return ResponseEntity.ok(authService.validateAndGetUser(token));
    }

    // 2. Com valor padrão e conversão automática de tipo
    @GetMethod("/items")
    public List<Item> listItems(@RequestHeader(value = "X-Page-Size", defaultValue = "20") int pageSize) {
        return itemService.list(pageSize);
    }

    // 3. Captura de todos os headers da requisição em um Map
    @GetMethod("/all-headers")
    public Map<String, String> getAllHeaders(@RequestHeader Map<String, String> headers) {
        return headers;
    }
}

⚙️ Controle Total de Respostas com ResponseEntity (Spring-Like)

A classe ResponseEntity<T> oferece total paridade com o Spring Boot para status HTTP, cabeçalhos fluentes e manipulação de respostas:

ResponseEntityExamples.java 
// 200 OK direto com corpo
return ResponseEntity.ok(usuario);

// 200 OK com encadeamento de cabeçalhos e builder
return ResponseEntity.ok()
        .contentType("application/json")
        .header("X-App-Version", "1.6.0")
        .body(usuario);

// 201 CREATED com header Location
return ResponseEntity.created("/api/users/42").body(novoUsuario);

// 202 ACCEPTED
return ResponseEntity.accepted().body("Processando em segundo plano");

// 204 NO CONTENT (sem corpo)
return ResponseEntity.noContent().build();

// 400 BAD REQUEST
return ResponseEntity.badRequest().body(Map.of("erro", "Parâmetros inválidos"));

// 404 NOT FOUND
return ResponseEntity.notFound().build();

// 422 UNPROCESSABLE ENTITY
return ResponseEntity.unprocessableEntity().body(errosValidacao);

// 500 INTERNAL SERVER ERROR
return ResponseEntity.internalServerError().body("Falha inesperada no servidor");

// Resolução elegante de Optional (200 OK se presente ou 404 NOT FOUND se vazio):
return ResponseEntity.of(userService.buscarOptionalPorId(id));
