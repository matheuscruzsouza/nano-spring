🗄️ SQLite & Migrações de Esquema (Flyway-style)

O Nano-Spring integra nativamente o SQLite do Android e oferece um migrador automático baseado em arquivos SQL versionados, garantindo que o banco de dados do aparelho evolua de forma previsível e segura.

🚀 Como Funciona

  1. Você cria arquivos SQL na pasta app/src/main/assets/db/migration/.
  2. Ao inicializar o Server, o SqliteMigrator consulta a tabela interna nano_schema_history.
  3. Apenas os scripts novos são executados em ordem de versão, cada um protegido por uma transação SQLite.
  4. A instância de SQLiteDatabase fica pronta para injeção via @Autowired em qualquer @Repository.

📁 Convenção de Nomes dos Scripts

⚠️
Atenção: O nome dos arquivos deve seguir rigorosamente a sintaxe V<versão>__<descrição>.sql com dois underscores (__). Exemplo: V1__create_tables.sql, V2__add_status.sql.

Exemplo 1: `V1__init_schema.sql`

assets/db/migration/V1__init_schema.sql 
CREATE TABLE IF NOT EXISTS categorias (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    nome TEXT NOT NULL
);

CREATE TABLE IF NOT EXISTS produtos (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    categoria_id INTEGER,
    titulo TEXT NOT NULL,
    preco REAL NOT NULL,
    FOREIGN KEY(categoria_id) REFERENCES categorias(id)
);

Exemplo 2: `V2__seed_data.sql`

assets/db/migration/V2__seed_data.sql 
INSERT INTO categorias (nome) VALUES ('Bebidas');
INSERT INTO categorias (nome) VALUES ('Lanches');

INSERT INTO produtos (categoria_id, titulo, preco) VALUES (1, 'Café Espresso', 5.50);
INSERT INTO produtos (categoria_id, titulo, preco) VALUES (2, 'Sanduíche Natural', 14.00);

💉 Injetando o SQLiteDatabase no @Repository

ProdutoRepository.java 
package com.exemplo.meuapp.repository;

import android.content.ContentValues;
import android.database.Cursor;
import android.database.sqlite.SQLiteDatabase;
import com.github.matheuscruzsouza.nanospring.annotation.Autowired;
import com.github.matheuscruzsouza.nanospring.annotation.Repository;
import java.util.ArrayList;
import java.util.List;

@Repository
public class ProdutoRepository {

    @Autowired
    private SQLiteDatabase db;

    public long inserir(String titulo, double preco, int categoriaId) {
        ContentValues cv = new ContentValues();
        cv.put("titulo", titulo);
        cv.put("preco", preco);
        cv.put("categoria_id", categoriaId);
        return db.insert("produtos", null, cv);
    }

    public List<String> listarTitulos() {
        List<String> lista = new ArrayList<>();
        try (Cursor cursor = db.rawQuery("SELECT titulo FROM produtos", null)) {
            while (cursor.moveToNext()) {
                lista.add(cursor.getString(0));
            }
        }
        return lista;
    }
}

⚙️ Configurações Opcionais (`application.properties`)

assets/application.properties 
# Nome do arquivo do banco SQLite (padrão: nano_spring_app.db)
nano.datasource.name=minha_empresa.db

# Caminho da pasta de migrações nos assets (padrão: db/migration)
nano.datasource.migration.location=db/migration

# Habilita ou desativa a execução automática (padrão: true)
nano.datasource.migration.enabled=true
