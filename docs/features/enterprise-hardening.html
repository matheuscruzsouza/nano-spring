🛡️ Módulo Enterprise & Resiliência Corporativa (v1.7.0)

O Nano-Spring v1.7.0 foi projetado para ambientes corporativos com restrições severas de hardware e processos em segundo plano (como maquininhas POS/PDV Android, totens de autoatendimento, coletores de dados e hubs IoT).

🏢
Todos os 5 pilares de estabilidade corporativa vêm habilitados por padrão com valores seguros, podendo ser afinados via application.properties.

1. Pool de Threads Controlado (Anti-OOM)

O NanoHTTPD original cria uma nova thread nativa no Linux para cada requisição recebida. Sob picos de tráfego em aparelhos modestos (1 GB de RAM), o sistema operacional encerra a aplicação com OutOfMemoryError: unable to create new native thread.

O ThreadPoolAsyncRunner substitui o executor padrão por um pool delimitado com fila de espera:

assets/application.properties 
# Threads mínimas sempre ativas (padrão: 4)
nano.server.threads.core=4

# Threads máximas para picos (padrão: 16)
nano.server.threads.max=16

# Capacidade da fila de conexões pendentes (padrão: 100)
nano.server.threads.queue-capacity=100

# Tempo ocioso para liberação de threads excedentes em segundos (padrão: 60)
nano.server.threads.keep-alive=60

2. Concorrência SQLite com Modo WAL (Write-Ahead Logging)

Por padrão, o SQLite no Android impede que uma thread leia o banco de dados enquanto outra estiver escrevendo, disparando SQLiteDatabaseLockedException.

O Nano-Spring ativa automaticamente o modo WAL (db.enableWriteAheadLogging()), permitindo leituras concorrentes em paralelo sem bloquear transações de escrita.

assets/application.properties 
# Ativação do modo Write-Ahead Logging (padrão: true)
nano.datasource.wal.enabled=true

3. Monitoramento Dinâmico de Rede & Reanúncio mDNS

Quando um roteador reinicia, o sinal Wi-Fi oscila ou o DHCP atribui um novo IP ao dispositivo Android, o NetworkWatcher detecta a troca de IP e renova o registro mDNS/DNS-SD automaticamente, sem necessidade de reiniciar o aplicativo.

assets/application.properties 
# Monitor de troca dinâmica de IP e conectividade (padrão: true)
nano.network.watcher.enabled=true

4. Classe Base NanoSpringService (Android Foreground Service)

Para manter o servidor HTTP ativo ininterruptamente sem ser finalizado pelo gerenciador de bateria do Android, herde de NanoSpringService:

MyServerService.java 
package com.minhaempresa.pdv;

import com.github.matheuscruzsouza.nanospring.service.NanoSpringService;

public class MyServerService extends NanoSpringService {

    @Override
    protected String getBasePackage() {
        return "com.minhaempresa.pdv";
    }

    @Override
    protected int getPort() {
        return 8080;
    }

    @Override
    protected String getNotificationTitle() {
        return "PDV Local Server";
    }
}

A classe base gerencia automaticamente:

  • Criação do NotificationChannel e notificação persistente.
  • Aquisição e liberação segura de PowerManager.WakeLock (mantendo a CPU acordada quando a tela apaga).
  • Aquisição de WifiManager.MulticastLock para tráfego mDNS.
  • Diagnóstico automático de status do Doze Mode / Otimizações de bateria.
  • Suporte a getCustomForegroundServiceType() para Android 10+ e 14+.
  • Parada limpa de todos os sockets no onDestroy().

Prevenindo Suspensão com a Tela Desligada (Doze Mode & Android 14+)

Para evitar que fabricantes (Samsung, Xiaomi, etc.) ou o Doze Mode matem o serviço com a tela apagada:

AndroidManifest.xml (App Cliente) 
<!-- Permissão opcional para solicitar isenção direta de Doze Mode -->
<uses-permission android:name="android.permission.REQUEST_IGNORE_BATTERY_OPTIMIZATIONS" />

<application>
    <service
        android:name=".MyServerService"
        android:exported="false"
        android:foregroundServiceType="dataSync" />
</application>

Utilize o BatteryOptimizationHelper para solicitar isenção de otimização de bateria ao usuário:

MainActivity.java 
import com.github.matheuscruzsouza.nanospring.service.BatteryOptimizationHelper;

if (!BatteryOptimizationHelper.isIgnoringBatteryOptimizations(this)) {
    Intent intent = BatteryOptimizationHelper.createRequestIgnoreBatteryOptimizationsIntent(getPackageName());
    startActivity(intent);
}
