✨ Novidades da Versão 1.10.0

O Nano-Spring v1.10.0 traz uma evolução histórica para o ecossistema Android: documentação viva e interativa com Nano-Swagger & OpenAPI 3.0.1 embutido, zero dependências externas de npm ou CDNs e funcionamento 100% offline em redes locais.

🚀 100% Retrocompatível: A versão 1.10.0 preserva compatibilidade integral com todas as APIs, anotações e controladores existentes da v1.9.0. Basta atualizar a dependência no Gradle.

📌 Destaques do Release

  • Interface Nano-Swagger Embutida: Acesse /swagger-ui no navegador do tablet, smartphone ou PC na mesma rede Wi-Fi e visualize todas as rotas registradas.
  • Especificação OpenAPI 3.0.1 Dinâmica: Endpoint GET /v3/api-docs gerado por reflexão em tempo real a partir das anotações das suas rotas.
  • Arquitetura Ultra-Leve (~15 KB): Sem pacotes NPM gigantescos (que chegavam a 10 MB no Swagger tradicional). Todo o HTML, CSS e Vanilla JS são embutidos e rodam de forma autônoma.
  • Runner Interativo ("Try it out"): Execute chamadas HTTP reais via fetch() diretamente da página, com visualização de tempo de resposta (ms), headers e payload formatado.
  • Mapeamento Automático de Bean Validation: Restrições como @NotNull, @Size, @Min, @Max e @Email nos seus DTOs são refletidas nos JSON Schemas da documentação.
  • Novas Anotações OpenAPI: Pacote com.github.matheuscruzsouza.nanospring.openapi.annotation com @Tag, @Operation, @Parameter e @ApiResponse.
  • Resiliência de Background & Doze Mode: Permissões automáticas no manifesto da biblioteca, gancho para getCustomForegroundServiceType() (Android 14+) e utilitário BatteryOptimizationHelper para prevenir encerramento de processos com a tela apagada.
  • Atualização de Telemetria: Endpoint GET /actuator/info agora reporta "version": "1.10.0".

📑 O que é o Nano-Swagger?

No desenvolvimento tradicional com Spring Boot, ferramentas como Springdoc ou Swagger-UI adicionam dezenas de megabytes de dependências e assets pesados. Em dispositivos móveis e embarcados (como PDVs de 1 GB de RAM ou TV Boxes), isso causaria consumo inaceitável de memória ou falhas de Out-Of-Memory.

O Nano-Swagger foi projetado do zero com uma filosofia mobile-first e embedded-first: um único arquivo de UI responsivo e elegante servido instantaneamente pela memória do servidor:

Endpoints Padrão 
# Interface gráfica interativa no navegador
http://<ip-do-android>:8080/swagger-ui

# Especificação OpenAPI 3.0.1 em JSON para importação no Postman ou Insomnia
http://<ip-do-android>:8080/v3/api-docs

📶 Arquitetura 100% Offline

A maioria das interfaces Swagger depende de CDNs externas (como cdnjs ou unpkg) para baixar fontes, ícones e scripts. O Nano-Swagger não depende de nenhuma conexão com a internet. Ele funciona perfeitamente em redes Wi-Fi ou Ethernet isoladas, permitindo que técnicos e equipes de integração testem endpoints de campo sem conectividade externa.

🏷️ Novas Anotações OpenAPI

Importe as anotações do pacote com.github.matheuscruzsouza.nanospring.openapi.annotation.*:

ProdutoController.java 
package com.exemplo.pdv.controller;

import com.github.matheuscruzsouza.nanospring.annotation.*;
import com.github.matheuscruzsouza.nanospring.http.HttpStatus;
import com.github.matheuscruzsouza.nanospring.http.ResponseEntity;
import com.github.matheuscruzsouza.nanospring.openapi.annotation.*;
import com.github.matheuscruzsouza.nanospring.validation.*;

@Tag(name = "Catálogo", description = "Gestão de produtos do PDV")
@RestController("/api/produtos")
public class ProdutoController {

    @Operation(summary = "Buscar produto por código de barras", description = "Retorna detalhes de preço e estoque")
    @GetMethod("/:ean")
    public ResponseEntity<ProdutoDTO> findByEan(
            @PathVariable("ean") @Parameter(description = "Código EAN-13 numérico", example = "7891000100103") String ean
    ) {
        return ResponseEntity.ok(new ProdutoDTO(ean, "Café Gourmet 500g", 24.90));
    }

    @Operation(summary = "Cadastrar produto")
    @ResponseStatus(HttpStatus.CREATED)
    @ApiResponse(responseCode = 201, description = "Produto cadastrado com sucesso", responseClass = ProdutoDTO.class)
    @ApiResponse(responseCode = 400, description = "Erro de validação dos campos")
    @PostMethod("")
    public ResponseEntity<ProdutoDTO> cadastrar(@Valid @RequestBody ProdutoDTO dto) {
        return ResponseEntity.status(HttpStatus.CREATED).body(dto);
    }
}

🛡️ Schemas & Validação Automática

Quando você utiliza Bean Validation nos seus DTOs, o gerador do OpenAPI extrai os metadados de validação e os anexa às definições de esquema em components.schemas:

ProdutoDTO.java 
public class ProdutoDTO {
    @NotBlank
    @Size(min = 8, max = 14)
    @Parameter(description = "Código de barras universal", example = "7891000100103")
    private String ean;

    @NotBlank
    @Size(min = 2, max = 100)
    private String descricao;

    @Min(0)
    private double preco;

    // Getters e Construtores...
}

📦 Como Atualizar para a v1.10.0

No arquivo build.gradle do seu projeto principal (app):

app/build.gradle 
dependencies {
    // Atualize a versão para 1.10.0
    implementation 'com.github.matheuscruzsouza:nano-spring:1.10.0'
}

⚙️ Configurações Opcionais

Você pode personalizar ou desativar o Swagger através do arquivo application.properties:

src/main/assets/application.properties 
# Habilitar ou desabilitar o Swagger (padrão: true)
nano.swagger.enabled=true

# Metadados do OpenAPI 3.0
nano.swagger.title=Minha API Android
nano.swagger.version=1.10.0
nano.swagger.description=Documentação interativa servida diretamente do Android
nano.swagger.server-url=/
