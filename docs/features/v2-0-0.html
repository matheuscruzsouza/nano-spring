Nova Versão 2.0.0 (Modularização e Profiles)

A versão 2.0.0 marca o maior avanço arquitetural do framework. Agora o Nano-Spring é fragmentado em múltiplos módulos (Core, Web, Data, Discovery) para reduzir ainda mais o tamanho das dependências, e introduz perfis dinâmicos focados em otimizar o uso da CPU e RAM em dispositivos de baixíssimo desempenho (Low Memory).

🧩 Arquitetura Modularizada

O framework não é mais um "monólito". Você importa apenas o que usar:

  • nano-spring-core: Injeção de dependência nativa e Logging (Base).
  • nano-spring-web: Servidor HTTP (NanoHTTPD), Controllers, Cors, OpenAPI.
  • nano-spring-data: Migrations e gerenciamento SQLite.
  • nano-spring-discovery: Busca e Anúncio na rede (mDNS / NSD).

⚡ Perfis Low Memory Dinâmicos

O Nano-Spring 2.0 consulta ativamente o ActivityManager do Android. Se um dispositivo tiver 2GB ou menos de RAM, ou disparar a flag de baixo recurso, o perfil low-memory é habilitado automaticamente!

Isso causa:

  • Agressiva redução de threads da piscina HTTP (evitando context switching na CPU).
  • Desligamento de serviços secundários gulosos como Swagger/Actuator por padrão.
  • Adoção silenciosa de callbacks nativos do sistema operacional como onTrimMemory para expurgar caches e forçar o Garbage Collector quando necessário.
