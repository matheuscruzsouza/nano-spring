📁 Upload & Streaming de Arquivos

O Nano-Spring oferece suporte nativo a multipart/form-data para uploads e transmissão em blocos (Chunked Transfer Encoding) para download de arquivos pesados sem sobrecarregar a memória do Android.

📤 Upload de Arquivos (@UploadedFile)

Use a anotação @UploadedFile("campo") recebendo um parâmetro do tipo java.io.File:

UploadController.java 
package com.exemplo.meuapp.controller;

import com.github.matheuscruzsouza.nanospring.annotation.PostMethod;
import com.github.matheuscruzsouza.nanospring.annotation.RestController;
import com.github.matheuscruzsouza.nanospring.annotation.UploadedFile;
import java.io.File;

@RestController("/api/arquivos")
public class UploadController {

    @PostMethod("/upload")
    public String receberArquivo(@UploadedFile("documento") File arquivoTemp) {
        if (arquivoTemp == null || !arquivoTemp.exists()) {
            return "Nenhum arquivo enviado.";
        }

        long tamanho = arquivoTemp.length();
        // Mova o arquivo da pasta temporária para o armazenamento permanente se necessário:
        File destino = new File(arquivoTemp.getParentFile(), "salvo_" + arquivoTemp.getName());
        arquivoTemp.renameTo(destino);

        return "Arquivo recebido com sucesso (" + tamanho + " bytes)!";
    }
}

📥 Download e Streaming em Chunks

Ao retornar diretamente uma instância de java.io.File, o Nano-Spring ativa transmissão em fluxo (streaming chunked):

DownloadController.java 
package com.exemplo.meuapp.controller;

import android.content.Context;
import com.github.matheuscruzsouza.nanospring.annotation.Autowired;
import com.github.matheuscruzsouza.nanospring.annotation.GetMethod;
import com.github.matheuscruzsouza.nanospring.annotation.PathVariable;
import com.github.matheuscruzsouza.nanospring.annotation.RestController;
import com.github.matheuscruzsouza.nanospring.http.HttpStatus;
import com.github.matheuscruzsouza.nanospring.http.ResponseEntity;
import java.io.File;

@RestController("/api/arquivos")
public class DownloadController {

    @Autowired
    private Context context;

    @GetMethod(value = "/download/:nome", mimeType = "application/octet-stream")
    public Object baixar(@PathVariable("nome") String nome) {
        File file = new File(context.getFilesDir(), nome);
        if (!file.exists()) {
            return ResponseEntity.status(HttpStatus.NOT_FOUND).body("Arquivo inexistente");
        }

        // O Nano-Spring injeta Content-Disposition e faz streaming em blocos!
        return file;
    }
}
⚡
Arquivos de centenas de megabytes são transmitidos direto do disco para o socket TCP em pequenas parcelas, sem risco de OutOfMemoryError.
