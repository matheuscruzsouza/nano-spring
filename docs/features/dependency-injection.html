💉 Injeção de Dependências & Configurações

O Nano-Spring implementa um container IoC (Inversion of Control) leve e eficiente que gerencia componentes no padrão Singleton, eliminando o acoplamento manual entre classes.

📌 Componentes Principais

Anotação Alvo Finalidade
@Service Classe Registra a classe como camada de serviço / regra de negócio singleton
@Repository Classe Registra a classe como camada de acesso a dados (DAO / SQLite)
@Autowired Campo Injeta uma dependência singleton registrada no container
@Value Campo Injeta propriedades lidas do application.properties

💡 Arquitetura em Camadas

Veja como estruturar Repositório, Serviço e Controlador com injeção automática:

1. Repositório (`@Repository`)

ClienteRepository.java 
package com.exemplo.meuapp.repository;

import android.database.Cursor;
import android.database.sqlite.SQLiteDatabase;
import com.github.matheuscruzsouza.nanospring.annotation.Autowired;
import com.github.matheuscruzsouza.nanospring.annotation.Repository;
import java.util.ArrayList;
import java.util.List;

@Repository
public class ClienteRepository {

    // O SQLiteDatabase é injetado automaticamente pelo framework!
    @Autowired
    private SQLiteDatabase db;

    public List<String> buscarNomes() {
        List<String> nomes = new ArrayList<>();
        try (Cursor c = db.rawQuery("SELECT nome FROM clientes", null)) {
            while (c.moveToNext()) {
                nomes.add(c.getString(0));
            }
        }
        return nomes;
    }
}

2. Serviço (`@Service`)

ClienteService.java 
package com.exemplo.meuapp.service;

import com.github.matheuscruzsouza.nanospring.annotation.Autowired;
import com.github.matheuscruzsouza.nanospring.annotation.Service;
import com.exemplo.meuapp.repository.ClienteRepository;
import java.util.List;

@Service
public class ClienteService {

    @Autowired
    private ClienteRepository clienteRepository;

    public List<String> listarClientesFormatados() {
        return clienteRepository.buscarNomes();
    }
}

3. Controlador (`@RestController`)

ClienteController.java 
package com.exemplo.meuapp.controller;

import com.github.matheuscruzsouza.nanospring.annotation.Autowired;
import com.github.matheuscruzsouza.nanospring.annotation.GetMethod;
import com.github.matheuscruzsouza.nanospring.annotation.RestController;
import com.exemplo.meuapp.service.ClienteService;
import java.util.List;

@RestController("/api/clientes")
public class ClienteController {

    @Autowired
    private ClienteService clienteService;

    @GetMethod("")
    public List<String> getClientes() {
        return clienteService.listarClientesFormatados();
    }
}

⚙️ Configurações com application.properties

Crie o arquivo assets/application.properties:

assets/application.properties 
server.port=9090
app.loja.nome=Android Server Store
app.desconto.maximo=25

Injete propriedades usando a anotação @Value com suporte a fallback padrão:

ConfigController.java 
@RestController("/api/config")
public class ConfigController {

    @Value("${app.loja.nome:Loja Padrão}")
    private String nomeLoja;

    @Value("${app.desconto.maximo:10}")
    private int descontoMaximo;

    @GetMethod("")
    public String getInfo() {
        return "Loja: " + nomeLoja + " | Desconto Máx: " + descontoMaximo + "%";
    }
}
