🎨 Templates HTML & Arquivos Estáticos

O Nano-Spring integra a biblioteca JMustache para renderização Server-Side de páginas HTML no Android e disponibiliza automaticamente qualquer asset estático sob a rota /static/.

📄 Renderização Server-Side (ModelAndView)

1. Crie o arquivo HTML de template

Salve seus templates na pasta app/src/main/assets/templates/:

assets/templates/painel.html 
<!DOCTYPE html>
<html lang="pt-BR">
<head>
    <meta charset="UTF-8">
    <title>{{titulo}}</title>
    <link rel="stylesheet" href="/static/css/style.css">
</head>
<body>
    <h1>Bem-vindo, {{usuario}}!</h1>
    
    <h3>Tarefas Pendentes:</h3>
    <ul>
        {{#tarefas}}
        <li>{{.}}</li>
        {{/tarefas}}
    </ul>
</body>
</html>

2. Retorne o ModelAndView no Controller

PainelController.java 
package com.exemplo.meuapp.controller;

import com.github.matheuscruzsouza.nanospring.annotation.GetMethod;
import com.github.matheuscruzsouza.nanospring.annotation.RestController;
import com.github.matheuscruzsouza.nanospring.ui.ModelAndView;
import java.util.List;

@RestController("/web")
public class PainelController {

    @GetMethod("/painel")
    public ModelAndView exibirPainel() {
        return new ModelAndView("painel")
                .addObject("titulo", "Painel Administrativo")
                .addObject("usuario", "Matheus")
                .addObject("tarefas", List.of(
                        "Conectar impressora Bluetooth",
                        "Sincronizar banco local",
                        "Subir servidor na porta 8080"
                ));
    }
}

⚡ Integração com HTMX

Retorne fragmentos HTML parciais definindo mimeType = "text/html":

FragmentoController.java 
@GetMethod(value = "/fragmento-status", mimeType = "text/html")
public String fragmentoStatus() {
    return "<div class='badge'>Dispositivo Online - " + System.currentTimeMillis() + "</div>";
}

📁 Hospedagem Automática de Arquivos Estáticos

Basta colocar seus arquivos na pasta app/src/main/assets/static/:

Estrutura de pastas 
app/src/main/assets/
└── static/
    ├── css/
    │   └── style.css
    ├── js/
    │   └── main.js
    └── img/
        └── android.png

Qualquer arquivo aí dentro é servido imediatamente com o MIME-type adequado em http://<servidor>:porta/static/...:

Referência no HTML 
<link rel="stylesheet" href="/static/css/style.css">
<script src="/static/js/main.js"></script>
<img src="/static/img/android.png" alt="Android">
