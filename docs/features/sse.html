📡 Server-Sent Events (SSE) em Tempo Real

Com a classe SseEmitter, o Nano-Spring viabiliza o envio contínuo de eventos do servidor Android diretamente para o navegador sobre uma única conexão HTTP persistente, dispensando WebSockets complexos.

💻 Implementação no Controller

Retorne SseEmitter e defina mimeType = "text/event-stream":

SensoresController.java 
package com.exemplo.meuapp.controller;

import com.github.matheuscruzsouza.nanospring.annotation.GetMethod;
import com.github.matheuscruzsouza.nanospring.annotation.RestController;
import com.github.matheuscruzsouza.nanospring.sse.SseEmitter;
import java.util.Map;

@RestController("/api/stream")
public class SensoresController {

    @GetMethod(value = "/leituras", mimeType = "text/event-stream")
    public SseEmitter streamLeituras() {
        SseEmitter emitter = new SseEmitter();

        // Inicia uma thread para alimentar os dados em tempo real
        new Thread(() -> {
            try {
                emitter.send("Conexão aberta com sucesso!");

                for (int i = 1; i <= 5; i++) {
                    Thread.sleep(1000);

                    // Envia eventos nomeados com JSON estruturado:
                    emitter.send("sensor_update", Map.of(
                            "temperatura", 24.5 + (i * 0.3),
                            "pressao", 1013,
                            "amostra", i
                    ));
                }

                emitter.complete(); // Encerra o fluxo com sucesso
            } catch (Exception e) {
                emitter.completeWithError(e);
            }
        }).start();

        return emitter;
    }
}

🌐 Consumindo no Frontend

1. JavaScript Puro com EventSource

app.js (Cliente) 
const sse = new EventSource('/api/stream/leituras');

// Escuta evento específico enviado com emitter.send("sensor_update", ...)
sse.addEventListener('sensor_update', (event) => {
    const dados = JSON.parse(event.data);
    console.log("Temperatura:", dados.temperatura + "°C");
});

sse.onerror = (err) => {
    console.log("Conexão encerrada pelo servidor.");
    sse.close();
};

2. Com HTMX (Extensão SSE)

index.html (HTMX) 
<div hx-ext="sse" sse-connect="/api/stream/leituras" sse-swap="sensor_update">
    <span>Aguardando dados do Android...</span>
</div>
